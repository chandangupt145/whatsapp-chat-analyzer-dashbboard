WhatsApp Chat Analysis and Visualization Dashboard

A powerful data analytics dashboard built using **Python** and **Streamlit** that analyzes exported WhatsApp chat files and generates meaningful insights through interactive visualizations.

## 🚀 Features

- 📩 Total Messages Analysis
- 📝 Total Words Count
- 🔗 Shared Links Detection
- 📷 Media Messages Count
- 👥 Most Active Users Analysis
- ☁️ Word Cloud Generation
- 📈 Monthly Timeline Analysis
- 📅 Daily Timeline Analysis
- 🔥 Activity Heatmap
- 😂 Emoji Usage Analysis
- 📊 Most Common Words Analysis
  
## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn
- WordCloud
- URLExtract
- Emoji

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/whatsapp-chat-analyzer.git
cd whatsapp-chat-analyzer
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Virtual Environment

#### Windows

```bash
.venv\Scripts\activate
```

#### Linux/Mac

```bash
source .venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

or

```bash
python -m streamlit run app.py
```

## 📁 Export WhatsApp Chat

1. Open WhatsApp.
2. Open any chat or group.
3. Click **More Options (⋮)**.
4. Select **Export Chat**.
5. Choose **Without Media**.
6. Save the `.txt` file.
7. Upload the exported file into the dashboard.
